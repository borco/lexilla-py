# lexilla-py has moved

This repository is archived. The `lexilla` package now lives in the
[scintilla-py](https://github.com/borco/scintilla-py) monorepo, under
[`packages/lexilla/`](https://github.com/borco/scintilla-py/tree/master/packages/lexilla),
next to [pyside6-scintilla](https://github.com/borco/scintilla-py/tree/master/packages/pyside6-scintilla).
Its full history (and the `lexilla-5.5.0.N` release tags) moved with it.

- Docs: <https://borco.github.io/scintilla-py/lexilla/>
- Issues: <https://github.com/borco/scintilla-py/issues>
- PyPI: <https://pypi.org/project/lexilla/> (the package name is unchanged)

```bash
pip install lexilla
```
